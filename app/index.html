🏛️ Core Architectural Principles

  • 🧩
    Image vs Container

    불변(Immutable) 레이어로 구성된 템플릿과 상태를 가지는 독립 실행 인스턴스

  • 🔒
    Network Namespace Isolation

    컨테이너 격리 영역과 호스트 현관문(Port Mapping)의 구조적 필수성

  • 💾
    Storage Persistence (Volume)

    컨테이너 소멸 이후에도 생존하는 완벽한 영속성 데이터 계층

  • 🛡️
    Linux Octal Permissions (755 vs 644)

    소유자/그룹/기타 권한 분리 및 Directory Search Bit(x) 메커니즘
